## LinkedIn

Every 15 minutes, a state grid is billed for every megawatt it misses.

We built **ADRMS — an Automated Demand Response Management System** — to run demand response end to end, from the moment a shortfall appears to the moment every participant is paid.

What you'll see in 86 seconds:

⚡ **Watch** — frequency, area control error and the deviation charge, every second, with data freshness checked at the source
🧭 **Decide** — a plan explained in plain language, with the operator approving
🔋 **Priority** — batteries first, industrial flexibility next, everything else after, and load rotation only as the last resort
📏 **Measure** — planned vs measured for every megawatt, because an instruction is not a reduction
🛡️ **Safety** — a digital twin screens each plan against line limits, battery charge and response time before dispatch
🏭 **Industry** — participation through offers on their own window, response time and price; delivery verified against a metered baseline
🔄 **Rotate** — what is left is rotated fairly, within spell limits, keeping hospitals and water works on, never without approval
🧪 **Test** — any shortage can be simulated first: no action, flexibility first or rotation-assisted
🧾 **Settle** — a counterfactual ledger for every event and a tamper-evident audit trail

Built as a simulation and advisory platform: the next step is validation with SLDC engineers on live telemetry.

If you work on grid operations, demand response or industrial flexibility, I'd value your perspective.
